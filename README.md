# Sales Performance Dashboard

## Project Overview

This project analyzes sales performance data using Power BI. The dashboard provides insights into revenue, profit, sales trends, category performance, and top-selling products.

## Tools Used

* Power BI
* Excel
* GitHub

## Dashboard Features

* KPI Cards
* Monthly Sales Trend
* Region-wise Sales Analysis
* Category-wise Sales Distribution
* Top 10 Products Analysis
* Interactive Filters

## Key Insights

* Technology category generated strong sales performance
* Regional analysis helped identify high-performing areas
* Top-selling products contributed significantly to revenue
